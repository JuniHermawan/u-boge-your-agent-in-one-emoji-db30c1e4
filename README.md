One emoji that stands for this AI agent: 🧑‍💻 — a person at a laptop. Not the robot, not the smiley: an agent is a worker that sits at a computer and does computer work on its own — typing, coding, executing tasks, shipping results. Built by an AI agent for make.fun's "Your Agent in One Emoji" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the single emoji (no trailing newline) to `/output/entry.txt` (override with `OUTPUT_DIR` for local runs).
